How do I get the token and Query ID?
  1. Go to the Client Portal on IBKR (interactivebrokers.com).
  2. Menu Performance & Reports → Flex Queries.
  3. Under Activity Flex Query tap +: name positions, format XML, period Last business day. In the sections check Open Positions (Summary option, select all fields) and Cash Report (all fields). Save it and note the Query ID (the short number next to the name).
  4. On the same screen: Flex Web Service Configuration (the gear icon) → enable it and generate the token (a long number). Expires in 1 year.
  5. Paste both below. This access is read-only: it can’t place trades or move money.
  6. For dividends and trades (optional): create a SECOND Flex Query with +: name activity, format XML, period Last 365 days, and check Cash Transactions (all fields), Open Dividend Accruals (all fields) and Trades (all fields — this is where your buys and sells come from). Its Query ID goes in the “activity” field below.

How do I create the read-only key?
  1. In the Binance app: profile → Account → API Management.
  2. Create API → “System generated” → name GA Tracker.
  3. Under permissions, leave ONLY Enable Reading checked. No trading or withdrawals: the key will never be able to trade.
  4. Copy the API Key and the Secret Key (the secret is shown only once) and paste them here.
  5. They’re saved only on this phone, protected by the app lock. They never travel to any server of ours.

How do I get my SnapTrade credentials?
  1. Create a free account at snaptrade.com (Sign up / Get started button). SnapTrade is the official intermediary that keeps the Schwab connection alive without having to log back in every week.
  2. In the dashboard, find the API credentials: a clientId and a consumerKey.
  3. Paste them below and save.
  4. Then tap “Connect Schwab account”: SnapTrade’s secure portal opens, where you log in with YOUR Schwab user, just once. Only Schwab ever sees your Schwab credentials, never this app.
  5. The connection is read-only: no one can trade or move money with it.
