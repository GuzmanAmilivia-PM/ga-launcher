IBKR

Interactive Brokers · conexión de solo lectura

Estado

Comprobando configuración...

Sincronización

Conexión

¿Cómo consigo el token y el Query ID?
  1. Entrá al Portal de Cliente de IBKR (interactivebrokers.com).
  2. Menú Rendimiento e informes → Consultas Flex (Performance & Reports → Flex Queries).
  3. En Actividad (Activity Flex Query) tocá el +: nombre posiciones, formato XML, período Último día hábil. En las secciones marcá Open Positions (opción Summary, seleccioná todos los campos) y Cash Report (todos los campos). Guardá y anotá el Query ID (número corto que queda junto al nombre).
  4. En la misma pantalla: Servicio web Flex (Flex Web Service Configuration, el engranaje) → activalo y generá el token (número largo). Vencimiento: 1 año.
  5. Pegá los dos acá abajo. Este acceso es de solo lectura: no permite operar ni mover plata.
  6. Para los dividendos (opcional): creá una SEGUNDA Flex Query con el +: nombre actividad, formato XML, período Últimos 365 días, y marcá las secciones Cash Transactions (transacciones de efectivo, todos los campos) y Open Dividend Accruals (dividendos devengados abiertos, todos los campos). Su Query ID va en el campo "actividad" de acá abajo.

Conexión

¿Cómo creo la clave de solo lectura?
  1. En la app de Binance: perfil → Cuenta → Gestión de API.
  2. Crear API → "Generada por el sistema" → nombre GA Tracker.
  3. En permisos dejá marcado SOLO Habilitar lectura. Nada de trading ni retiros: la clave no podrá operar jamás.
  4. Copiá la API Key y la Secret Key (la secreta se muestra una sola vez) y pegalas acá.
  5. Quedan guardadas únicamente en este teléfono, protegidas por el bloqueo de la app. Nunca viajan a un servidor propio.

Charles Schwab

Conexión automática de solo lectura vía SnapTrade

Estado

Comprobando configuración...

Sincronización

Conexión

¿Cómo consigo las credenciales de SnapTrade?
  1. Creá una cuenta gratis en snaptrade.com (botón Sign up / Get started). SnapTrade es el intermediario oficial que mantiene la conexión con Schwab sin que haya que reloguearse cada semana.
  2. En el panel (dashboard), buscá las API credentials: un clientId y una consumerKey.
  3. Pegalas acá abajo y guardá.
  4. Después tocá "Conectar cuenta Schwab": se abre el portal seguro de SnapTrade donde entrás con TU usuario de Schwab, una sola vez. Tus credenciales de Schwab las ve solo Schwab, nunca esta app.
  5. La conexión es de solo lectura: nadie puede operar ni mover plata con ella.
